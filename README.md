# Аналитика по продаже товаров в сети магазинов

_Ожидаемые пользоваели - управляющей магащинов и территориальные управляющие_

## 1. Генерация данных и загрузка в БД

Были сгенерированы на Python и загружены в локально развернутую БД PostgresSQL. 
Генерация была осуществлена со следующими допущениями:

- Продажи осуществляются в течение двух лет
- В 2025 году в системе лояльности зарегистрированно больше чем в 2024
- В выходные пробивается больше чеков, чем в будни
- Все магазины работают с 7 до 23
- Часть клиентов не прикладывает карту магазина - они неавторизированные пользователи
- Цена продукта генерируется согласно рамкам, установленных для его категории
- Маржинальность задана от 15 до 34%
- Сктдка не может бытб более 30%

## 2. Описание дашборда Power BI

_Предполагается, что для всего отчета будет использоваться сквоздной фильтр по текущему году_

### KPI для подразделений

- Позволяет отслеживать основные показатели управляющими по своему магазину и по нескольким (для территориальных)
- Отдельно выделяется лидер по выручке, так как это достижение дает сотрудникам магазина + к з/п
- Также выведен общих рейтинг, чтобы дргуие магизины видели сколько им не хватает, чтобы стать первыми
- График покупок по часам выведен для планирования вывода на смену разного количества сотрудников

### Сегментация продуктов - ABC-анализ

- Предполагается, что управляющий кадждого магизина отследиваемость продаваемость каждого продукта и может влиять на товарную матрицу
- Прибыль по дням недели необходима, чтобы своевременно запланировать поплнение запасов при наличии серьезных всплесков
- Топ 3 по прибыли - позиции, которым необходимо держать увеличенный товарный запас

### Сегментация продаж - RFM-анализ

- На карточках средние показетели по Rececy, Frequency и Monetary, у каждой внизу динамока отнсительно прошлого года, чтобы магазины могли отследживать свой прогресс (или заметить проблемы)
- % покупок со скидочной картой - один из целевых показелей для управляющих магазинов. Головная компания заинтересована, чтобы как можно больше клиентов учавствовали в бонусной программе
